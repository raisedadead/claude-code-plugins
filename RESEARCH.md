# RESEARCH.md

Companion to [`ARCHITECTURE.md`](./ARCHITECTURE.md), which holds what we believe now; this holds why, what we refused, and what is still owed.

Not append-only — see "Collapse, don't stack" below. Optimised to be read by a session with no memory of this one, not to be a complete account of how we got here.

Long-form research and working notes stay in `.scratchpad/` — untracked, local, disposable. Only what survives contact with a future session belongs here.

## How to write a row

- **One line per row.** If it needs a paragraph, it does not belong here.
- **A decision row without a rejected alternative is a description, not a decision.** Drop it or find the alternative.
- **Facts carry a recheck trigger**, never "forever". Harness versions, registries and star counts all rot.
- **Evidence must survive.** A commit SHA, a git-tracked path, or a URL. Never a `.scratchpad/` path — that directory is ignored and invisible to everyone else.
- **Collapse, don't stack.** When a decision reverses, rewrite the row in place. Keep every alternative still worth refusing; drop the positions we merely passed through. A reader needs what is true now and what not to re-propose — the route we took to get there is archaeology, and git history already holds it. Changing your mind twice in a day is normal and costs nothing; making the next reader page through both attempts is what costs.
- **Delete a row the moment it stops changing a decision.** A ledger earns its place by being read. Every row that no longer alters what someone would do is drag on the ones that do.
- **Open stride states:** `open`, `landed <sha>`, `partial`, `dropped: <why>`.
- **Check the stride table against your own diff before committing.** Rows describing work in progress go stale between being written and being committed — three did on this file's first day. A ledger that misdescribes the repo argues against its own existence.
