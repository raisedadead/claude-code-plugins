# RESEARCH.md

Append-only record. Companion to [`ARCHITECTURE.md`](./ARCHITECTURE.md), which holds what we believe now; this holds how we got here and what is still owed.

Long-form research and working notes stay in `.scratchpad/` — untracked, local, disposable. Only what survives contact with a future session belongs here.

## How to write a row

- **One line per row.** If it needs a paragraph, it does not belong here.
- **A decision row without a rejected alternative is a description, not a decision.** Drop it or find the alternative.
- **Facts carry a recheck trigger**, never "forever". Harness versions, registries and star counts all rot.
- **Evidence must survive.** A commit SHA, a git-tracked path, or a URL. Never a `.scratchpad/` path — that directory is ignored and invisible to everyone else.
- **Supersede, don't edit.** Add a new row citing the id it replaces. Strides flip state; they are never deleted.
- **Open stride states:** `open`, `landed <sha>`, `partial`, `dropped: <why>`.
- **Check the stride table against your own diff before committing.** Rows describing work in progress go stale between being written and being committed — three did on this file's first day. A ledger that misdescribes the repo argues against its own existence.
