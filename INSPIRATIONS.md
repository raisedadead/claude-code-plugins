# INSPIRATIONS.md

What we borrowed, what we refused, and when we last looked. One row per source.

A refusal is worth as much as an adoption: without it the next survey re-proposes the thing we already turned down, at full cost. `RESEARCH.md` holds the same rule for our own decisions — this file holds it for other people's.

**Stamp.** Every release surveys this file. When a plugin `CHANGELOG.md` gains a dated section, each source read for it gets its `surveyed` cell set to that date, whether or not anything changed. A survey that found nothing is data: it dates the claim "we are still current". A source nobody read keeps its old date. Convention, not enforcement — no hook checks it.

`surveyed` is the date someone read the source and classified what was there. It is not the date we copied something.

## Adoption order

Native or built-in first. Absorb into our own plugin second. Third-party last, and by default never — no new third-party plugins, no new marketplace.

**An evaluation install is not an adoption.** Installing a source to read it under load is how a survey gets past reading the README, and it commits us to nothing. The order above governs what we take, not what we look at. Say which one a row is, with the date, so a later session reading `installed_plugins.json` against this file does not report drift that was a deliberate test — and so an install that quietly became a dependency is visible as one.

The classification step is not optional, and both failure modes are on record in this file's own history: the 2026-07-11 survey overstated our review gap and retracted it (the `mattpocock/skills` and `spec-kit` rows carry what survived), and the 2026-08-02 source-fidelity pass found the opposite — Completion Criterion and Negation had been harvested from `mattpocock/skills` while the lineage table credited it only with `ds:grill` (F28, and the row below). Enumerate the whole surface, classify each item `have-equivalent` / `refused-with-reason` / `gap`, then run a corrections pass against our own findings before adopting anything.
